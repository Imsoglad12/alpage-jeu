# Alpage

Un berger, son chien et son troupeau dans les Alpes suisses. Un jeu en 3D, fait maison, pour PC Windows.

## Télécharger

**[Télécharger la dernière version](https://github.com/Imsoglad12/alpage-jeu/releases/latest)**, puis cliquer sur le fichier `Alpage-….zip` dans la liste « Assets ».

1. Dézipper le dossier où tu veux, par exemple sur le Bureau.
2. Double-cliquer sur `Alpage.exe`.
3. Si Windows affiche « Windows a protégé votre ordinateur », cliquer sur « Informations complémentaires » puis « Exécuter quand même ». Le jeu n'est pas signé numériquement, c'est normal pour un jeu fait maison.
4. Le premier chargement prend environ 20 secondes.

Il faut Windows 10 ou 11 (64 bits). Une carte graphique de jeu est conseillée. Si le jeu est lent : Échap, Réglages, Qualité graphique « Basse », puis relancer.

## Le but : les paliers

- Un seul objectif à la fois, en haut à gauche, et une flèche dorée qui montre où aller.
- Les premiers paliers apprennent le métier : appeler le troupeau, le chien, la tonte, le marchand, les clôtures, le fromage...
- Au début, on ne construit que des clôtures. Portail, abreuvoir, râtelier, bergerie et pierre à sel se débloquent au fil des paliers.
- Ensuite les paliers ne s'arrêtent jamais : un troupeau de 20, 35, 50 moutons et plus, la laine, les fromages, les économies, les agneaux, les hivers sans perte. Le titre du berger monte avec eux, jusqu'à « légende de l'alpage ».
- La difficulté monte doucement : le premier hiver est doux, les suivants de plus en plus rudes, et les moutons deviennent plus têtus et indépendants avec les années.

## Le jeu

- Tu joues le berger ou son chien, un bouvier d'Appenzell (touche Tab).
- Des moutons nez noirs du Valais, chacun avec son prénom et son caractère. Les agneaux suivent leur mère.
- La laine pousse jour après jour, et on tond les moutons à la main.
- Le chien rassemble le troupeau, va chercher les égarés, contourne les clôtures, se couche ou part là où tu regardes.
- Les moutons ont soif, faim, besoin de sel et d'un abri. Au printemps naissent les agneaux (parfois des jumeaux, rarement un agneau noir).
- On trait les brebis qui allaitent et on fait du fromage au poêle du chalet. Il s'affine en 3 jours.
- Le marchand monte avec sa mule tous les 3 jours, ou quand on sonne sa cloche. Le village de Saint-Alpin, en bas de la vallée, paie mieux.
- Quatre saisons de 5 jours. L'hiver, la neige couvre tout : foin dans le râtelier et bergerie la nuit.
- Le jour et la nuit, le chalet où l'on peut entrer et dormir, le lac où l'on nage, le ruisseau et la fontaine.
- La partie se sauvegarde toute seule.

## Commandes

Toutes les touches se changent dans Échap, Réglages, Changer les touches.

| Touche | Action |
|---|---|
| Z Q S D (W A S D) ou flèches | se déplacer |
| Souris, molette | regarder, rapprocher la caméra |
| Maj | courir vite |
| C | marcher doucement (les moutons ont peur de qui court) |
| X ou Verr. Num | course automatique |
| Espace | sauter |
| Tab | jouer le berger ou le chien |
| E | agir : tondre (rester appuyé), portes et portails, râtelier, sel, fromage, commerce, cloche, dormir |
| T (rester appuyé) | traire une brebis qui allaite |
| R | appeler le troupeau |
| 1, 2, 3 | chien : rassemble, au pied, couché |
| Clic droit | chien : va là où tu regardes |
| Clic gauche (en chien) | aboyer |
| B | mode construction |
| H, Échap, F5, F11 | aide, pause, sauvegarder, plein écran |
